# Wash Junction — Cheese Team model set

Game-ready props for the Wash Junction CTF map: a desert highway truck stop and cheese depot. The style is modern industrial with a little Old West.
The brief is in [SPEC.md](SPEC.md). Every mesh is generated by a Python build script and baked from procedural PBR
materials. No hand-painted or downloaded textures are used.

- **Browse:** open [`export/index.html`](export/index.html) through any static server. It shows preview renders, stats and an in-browser GLB viewer.
- **Table:** [ASSETS.md](ASSETS.md) lists triangles, sizes, slots and collision for every mesh.

## What each asset folder contains (`export/<Name>/`)
| File | What |
|---|---|
| `SM_<Name>.fbx` | Unreal mesh: 1 unit = 1 cm, transforms applied, smoothing groups, triangulated, with `UCX_SM_<Name>_NN` convex collision |
| `SM_<Name>_LOD1.fbx` | ~50% LOD for meshes over 5k tris (import it as LOD 1 in the Static Mesh Editor) |
| `SM_<Name>.glb` | Web preview in metres (glTF Y-up), textures embedded as JPEG, OpenGL normal map |
| `T_<Name>_BaseColor.png` | sRGB albedo (RGBA with an alpha mask for alpha-tested cards). No baked lighting. |
| `T_<Name>_Normal.png` | Tangent-space normal, **DirectX convention (green = −Y)**, ready for Unreal |
| `T_<Name>_ORM.png` | R = ambient occlusion, G = roughness, B = metallic (linear) |
| `SM_<Name>_preview.jpg` | Front three-quarter render (Cycles, desert sky) |
| `SM_<Name>.report.json` | Triangles, LOD1 tris, bbox vs target, pivot, texel density, slots, UCX count |

Variants that share a texture set (e.g. `SM_Lockers_1_Open`, `SM_CheeseRack_Empty`) sit in their base asset's folder.
Extra texture sets on one mesh (the cheese wheel rinds) are named `T_<Name>_<Skin>_*`.

## Conventions
- Z up, the **front faces +X**, real-world metres. Spec sizes are W × H × D, so the bbox is X = D, Y = W, Z = H.
- The pivot is at the bottom centre unless the spec says otherwise:
  - flag cheeses: at the centre
  - semi trailer: under the king-pin
  - windmill wheel and valve wheel: at the hub
- Material slots:
  - `M_<Name>`: everything that is baked.
  - `TeamPaint`: neutral light-grey chipped paint or cloth. Multiply by Cheddar `#C8601C` or Bleu `#33669F`.
  - `Glow`: emitter strips; drive emissive from BaseColor × team colour.

  All slots share one UV set and one texture set.
- No text anywhere. Sign faces are blank.

## Unreal import
1. Import `SM_<Name>.fbx` with the defaults.
   - Units are already centimetres, so leave Import Uniform Scale at 1 and Convert Scene on.
   - UCX meshes become collision automatically.
   - Leave Combine Meshes on.
2. Texture settings:
   - BaseColor: sRGB on.
   - Normal: compression `Normalmap`. It is already DirectX, so don't flip green.
   - ORM: sRGB **off**, compression `Masks`.
3. Materials:
   - A master material reads ORM (R→AO, G→Roughness, B→Metallic).
   - `TeamPaint` instances multiply BaseColor by the team colour.
   - `Glow` instances add an emissive term.
4. LOD1: Static Mesh Editor → LOD Settings → *Import LOD Level 1* → `SM_<Name>_LOD1.fbx`.

## Rebuilding
Requirements: Blender 4.0 (headless is fine), plus system Python 3 with numpy and Pillow (used to write the PNGs).
```bash
blender -b -P src/<script>.py -- --draft      # fast check: live procedural shading, no bake
blender -b -P src/<script>.py                 # bake + export everything for that script
blender -b -P kit/inspect.py -- export/<Name>/SM_<Name>.glb   # 4-view contact sheet
python3 gallery/build_gallery.py              # refresh export/index.html + ASSETS.md
```
How a build works (see [kit/KIT.md](kit/KIT.md) for the API):
1. Parts are built as bmesh in their own frames. Each part stores its local coordinates (`lco`) so wood grain,
   brushing and streaks follow the part.
2. Booleans are exact.
3. Smart UV unwrap.
4. A mask pre-bake (edge wear, cavity and AO by ray tracing) feeds the procedural recipes in `kit/materials.py`:
   chipped paint, rust, galvanised steel, timber, board-formed concrete, burlap, wax, cheeses, chrome and more.
5. The colour, roughness/metal and normal passes are baked in Cycles. Rounded edges come from a Bevel-node normal bake.

## Honest limits
- The materials are procedural recipes baked to textures, not photoscans. They are tuned to read as worn, sun-faded desert hardware, but
  close-up they won't match a scan's micro-detail.
- Triangle budgets are respected. Fine detail such as grating, louvres and razor-wire barbs comes from the normal map or an alpha mask, not geometry.
